# 📚 Трекер чтения книг (Book Reading Tracker)

> Итоговый мини-проект по дисциплине «Веб-технологии» (Лабораторная работа №8, Вариант 16).
> Полнофункциональное веб-приложение для учёта прочитанных страниц, визуализации прогресса и ведения статистики чтения.

---

## 🌟 Основные возможности

Приложение реализует полный цикл работы с данными (**CRUD**) и предлагает удобный интерфейс для анализа привычек чтения:

*   **Управление записями (CRUD):** добавление, просмотр, редактирование и удаление записей о прочитанных страницах.
*   **Фильтрация по периоду:** быстрая выборка записей за последнюю неделю, месяц или за всё время.
*   **Сводная статистика:** автоматический подсчёт суммарно прочитанных страниц за выбранный период.
*   **Прогресс-бары по книгам:** наглядное отображение того, какой процент от общего объёма книги уже прочитан (на основе HTML-тега `<progress>`).
*   **Интерактивный календарь:** визуализация дней текущего месяца, в которые пользователь читал книгу.
*   **Адаптивный дизайн:** интерфейс корректно отображается как на десктопных мониторах, так и на экранах мобильных устройств.
*   **Модальные окна:** создание и редактирование записей происходит в нативном диалоговом окне `<dialog>` без перезагрузки страницы.

---

## 🛠️ Стек технологий

**Frontend:**
*   HTML5 (Семантическая разметка)
*   CSS3 (Flexbox, CSS Grid, CSS-переменные, адаптивная вёрстка)
*   Vanilla JavaScript (ES6+, Fetch API, работа с DOM, модульный подход)

**Backend:**
*   Node.js
*   Express.js (REST API, маршрутизация, статика)

**База данных:**
*   SQLite (через драйвер `better-sqlite3`)
*   Валидация данных на уровне БД (`CHECK` constraints)

## 🚀 Установка и запуск

Для запуска проекта вам потребуется установленный **Node.js** (версия 16 или выше).

1. **Клонируйте репозиторий** (или скачайте папку с проектом):
   ```bash
   git clone <ссылка-на-ваш-репозиторий>
   cd reading-tracker
   ```
2. **Установите зависимости**
   ```bash
   npm install
   ```
   После этой команды из package.json загрузятся express и better-sqlite3
3. **Заполните базу данных текстовыми данными**
   ```bash
   node scripts/seed.js
   ```
4. **Запустите сервер**
   ```bash
   npm start
   ```
5. **Откройте приложение**
   Перейдите в браузер по адресу: http://localhost:3000

## 📂 Архитектура проекта

Проект имеет четкое разделение на клиентскую и серверную части, а также слой работы с базой данных:
```text
reading-tracker/
├── db.js                  # Инициализация SQLite и применение схемы
├── server.js              # Точка входа, настройка Express
├── package.json           # Зависимости и скрипты
├── sql/
│   └── schema.sql         # SQL-скрипт создания таблиц и индексов
├── scripts/
│   └── seed.js            # Скрипт добавления тестовых данных
├── routes/
│   └── logs.js            # REST API (CRUD + статистика)
└── public/                # Клиентская часть (раздается Express)
    ├── index.html         # Главная страница (SPA-подобная)
    ├── css/
    │   └── style.css      # Стили и адаптивность
    └── js/
        └── app.js         # Логика работы с API и рендеринг UI
```

## 📡 Rest API Endpoints

Серверная часть предоставляет следующие маршруты:

| Метод |	Маршрут |	Описание
| :--- | :--- | :---|
| `GET`	| `/api/logs` |	Получить список записей. Поддерживает параметры ?from=YYYY-MM-DD&to=YYYY-MM-DD |
| `GET` |	`/api/logs/stats` |	Получить агрегированную статистику (?period=week или ?period=month) |
| `GET` |	`/api/logs/:id` |	Получить одну запись по ID |
| `POST`	| `/api/logs` |	Создать новую запись |
| `PUT`	| `/api/logs/:id`	| Обновить существующую запись |
| `DELETE` | `/api/logs/:id`	| Удалить запись |
